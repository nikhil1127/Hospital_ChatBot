📁 HOSPITAL KNOWLEDGE BASE
==========================

Add your hospital documents here to teach the bot!

SUPPORTED FILE TYPES:
- 📄 PDF files (.pdf) - Brochures, policies, doctor profiles
- 📝 Text files (.txt) - FAQs, instructions
- 📋 Markdown files (.md) - Documentation

WHAT TO ADD:
------------
1. Hospital brochures with services and facilities
2. Doctor profiles with qualifications
3. Insurance and billing policies
4. Visiting hours and location details
5. Procedure packages and pricing
6. FAQs commonly asked by patients

EXAMPLE FILES:
--------------
- visiting_hours.pdf
- insurance_policy.pdf
- doctor_profiles.pdf
- location_and_parking.txt
- procedure_packages.pdf
- faqs.txt

HOW TO INDEX:
-------------
1. Copy your files to this folder
2. Run: python index_docs.py
3. The bot will now answer from these documents!

TIP: The bot searches by keywords, so clear document titles help.
